Methodology guide

How the model chooses useful Operator X sites.

A picture-first explanation of geographic gaps, local density, and why selected sites should not bunch together.

Important boundary This is a map-based planning aid. It finds geographic gaps, but it cannot see radio signal, hills, buildings, users, traffic, capacity, cost, or site readiness.

The whole idea in one sentence

Choose X sites that are far enough from B sites to fill useful spaces, while avoiding a portfolio in which many chosen X sites sit almost on top of one another.

BExisting B site XX candidate ✓Selected X site ×Too close / redundant

Step 1: Measure the gap to Operator B

Think of umbrellas in the rain

B sites are existing umbrellas. An X candidate standing far from every B umbrella may cover an exposed space. An X candidate beside a B umbrella probably adds less new geographic reach.

Absolute scoring uses only this shortest distance in kilometres.

Step 2: Ask whether the area is crowded or spread out

The same 3 km gap can mean something different in a city and in the countryside. Density scoring compares the X-to-B gap with the normal spacing of nearby B sites.

density gap ratio = distance from X to nearest B ÷ typical spacing among nearby B sites

A ratio above 1 means the gap is larger than the usual local B spacing. A ratio below 1 means the gap is smaller than the usual local spacing.

Step 3: Keep selected X sites useful as a group

Why the circle changes size

With automatic diversity distance, the circle uses local B spacing. It is smaller in dense areas and larger in sparse areas. This avoids using one city-sized rule everywhere.

Diversity penalty: reduces the score of an X site close to a selected X site.

Saturation penalty: reduces the score again when several selected X sites already fall inside its local circle.

Hard spacing: can completely reject a candidate that is too close. Leave it at 0 when you want soft ranking only.

Step 4: Build the portfolio one site at a time

marginal score = gap score × [1 − diversity weight × diversity penalty − saturation weight × saturation penalty]
Simple example: an X site starts with 80 gap points. Nearby selected sites create a 10-point diversity reduction and a 5-point saturation reduction. Its current value becomes about 65 points. This is an illustration; the app uses factors between 0 and 1.

Fixed-count mode

Use this when the agreement or budget says exactly how many sites may be chosen. The model keeps picking the best current candidate until it reaches the count. A hard spacing rule can leave fewer sites if too many candidates overlap.

Suggested baseline

Density scoring, required count, 5 local B neighbours, 5 local X neighbours, automatic diversity, weights 0.20 and 0.10, minimum spacing 0.

Threshold mode

Use this when every site above a geographic-gap rule should qualify. Select all qualifying sites keeps them all; diversity changes their order only. De-clustered portfolio can remove sites that break the hard spacing rule.

How to read the output

Local X spacing
Typical distance between nearby X candidates. Small means a crowded candidate cluster.
X/B spacing ratio
Local X spacing divided by local B spacing. Below 1 means X candidates are packed more tightly than B sites nearby.
Nearest selected X
Distance to the closest X site already chosen at that selection step.
Selected-X neighbours
Number of already selected X sites inside the candidate’s local diversity circle.
Diversity factor
A 0-to-1 separation measure. A value of 1 means the candidate meets or exceeds its spacing target.
Saturation factor
Falls as more selected sites appear in the same local circle.
Marginal score
The gap value after diversity and saturation reductions. The highest current value is picked next.
Redundancy filtered
The site passed the gap rule but failed the optional hard X-to-X spacing rule.

A safe tuning sequence

  1. Run the recommended baseline with minimum spacing ratio 0.
  2. On the map, confirm that the larger gold Selected X circles fill useful spaces.
  3. Look for gold circles bunching together and inspect nearest-selected-X distances.
  4. If needed, raise diversity weight from 0.20 to 0.25, then 0.30.
  5. If one area still receives too many choices, raise saturation weight slightly.
  6. Only when near-duplicates must be prohibited, try minimum spacing ratio 0.5.
  7. Validate the final shortlist with RF prediction, sectors, bands, terrain, traffic, capacity, cost, and field evidence.

Calculation performance

The engine uses fast in-memory nearest-neighbour searches. A spatial database is not needed for the expected 6,000 B sites and 12,000 X sites in Phase 1.

Map loading

Selected X sites are larger gold circles and are drawn after other sites so they stay visible. Map points render locally in batches; only the OpenStreetMap background tiles require internet.
